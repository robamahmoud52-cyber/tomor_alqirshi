# 🌴 تمور القرشي | Quraishi Dates

موقع احترافي لعرض أصناف التمور واستقبال طلبات المحلات التجارية، مع قاعدة بيانات حقيقية،
لوحة تحكم محمية، وإشعارات تصل إلى جوّالك فور وصول أي طلب.

---

## 📁 بنية المشروع

```
تمور القرشي/
├─ index.html              ← الصفحة الرئيسية (HTML منفصل)
├─ css/styles.css          ← تنسيقات الموقع (CSS منفصل)
├─ js/app.js               ← السلة + تبديل اللغة + الإرسال
├─ js/catalog.js           ← بيانات الأصناف (15 صنف × 3 خيارات)
│
├─ admin/index.html        ← لوحة التحكم (HTML منفصل)
├─ admin/admin.css         ← تنسيقات اللوحة (CSS منفصل)
├─ admin/admin.js          ← منطق اللوحة + البث المباشر
│
├─ server/server.js        ← الخادم (HTTP + API)
├─ server/db.js            ← قاعدة البيانات (SQLite)
├─ server/notify.js        ← الإشعارات (واتساب / SMS / تيليجرام …)
├─ server/config.js        ← قراءة الإعدادات
├─ server/config.json      ← ★ إعداداتك (ضع بياناتك هنا)
│
├─ assets/dates/*.svg      ← صور الأصناف
├─ tools/generate-images.js← مولّد الصور
├─ tools/test.js           ← الاختبار الشامل (npm test)
├─ tools/test-notify.js    ← اختبار إرسال رسالة ل جوّالك
├─ tools/static-preview.js ← معاينة الواجهة بدون خادم
├─ data/orders.db          ← قاعدة البيانات (تُنشأ تلقائيًا)
└─ start.bat               ← تشغيل بضغطة واحدة
```

**التقنية:** Node.js 22+ فقط — بدون أي مكتبة خارجية (قاعدة البيانات SQLite مدمجة في Node).
لا حاجة لـ `npm install` إطلاقًا.

## 🚀 التشغيل على الكمبيوتر

### الطريقة الأولى (الأسهل)
اضغط مرتين على **`start.bat`** ← يفتح المتصفح تلقائيًا على `http://localhost:3100`

### الطريقة الثانية (أوامر)
```bash
npm start           # تشغيل الخادم والموقع ولوحة التحكم
npm test            # تشغيل الاختبار الشامل (27 فحصًا)
npm run test:notify # إرسال رسالة تجريبية إلى جوّالك
npm run images      # إعادة توليد صور الأصناف
```

> **المنفذ 3100** (وليس 3000) لأن مشروعًا آخر على جهازك يستخدم 3000.
> لتغييره: عدّل `port` في `server/config.json`.

### ⚠️ سبب رسالة «تعذّر إرسال الطلب» التي واجهتك
الموقع يحتاج **الخادم** لاستقبال الطلبات. إذا فتحت `index.html` بالنقر المزدوج
(بروتوكول `file://`) أو من خادم ملفات لا يحتوي الـAPI، يفشل الإرسال.

**الحل:** شغّل `start.bat` ثم افتح `http://localhost:3100` (وليس فتح الملف).
وكحل إضافي أضافه الموقع: إذا كانت الواجهة على نطاق مختلف، يكتشفها تلقائيًا
ويلجأ إلى خادم الطلبات على `localhost:3100`.

## 🛒 لوحة التحكم

| العنصر | التفاصيل |
|---|---|
| الرابط | `http://localhost:3100/admin/` |
| كلمة المرور الافتراضية | `quraishi2026` |
| تغييرها | `server/config.json` → `adminPassword` |

**المزايا:** عرض كل الطلبات · اسم المحل · الأصناف وخياراتها وكمياتها · التاريخ والوقت ·
البحث · تصفية الحالة (جديد / تمت المراجعة / تم التجهيز / تم التسليم / ملغي) ·
تغيير الحالة · حذف الطلب · **تنبيه صوتي وبث مباشر** عند وصول طلب جديد (SSE).

> الحماية: كلمة المرور في الخادم فقط، الجلسة بكوكي `HttpOnly`،
> ولا يمكن الوصول لملف الإعدادات أو قاعدة البيانات من المتصفح (403).

## 🔔 كيف أعرف أن العميل طلب؟ — أربع طرق مضمونة

| الطريقة | كيف تشتغل | متى تُفعّلها |
|---|---|---|
| **١. لوحة التحكم** (مفعّلة) | `http://localhost:3100/admin/` — الطلب يظهر **فورًا** + صوت تنبيه + تحديث تلقائي (SSE) + عدّاد «طلبات جديدة» في التبويب | جاهزة الآن ✅ |
| **٢. تنبيه شاشة الكمبيوتر** | زر «🔔 تفعيل التنبيه» في اللوحة ← يpopup إشعار ويندوز مع اسم المحل وأصنافه (حتى لو كانت اللوحة في الخلفية) | تضغط الزر مرة واحدة ✅ |
| **٣. واتساب على جوّالك** | CallMeBot يرسل لك رسالة الطلب على `+966565283375` | تحتاج مفتاح التفعيل (خطوة واحدة) ⬇️ |
| **٤. رسالة SMS** | Twilio يرسل رسالة نصية قصيرة | تحتاج حساب Twilio |

### ✅ تفعيل واتساب على رقمك (0565283375) — خطوة واحدة فقط
رقمك جاهز في الإعدادات: `+966565283375`. المتبقي هو **مفتاح CallMeBot**:

1. من واتساب **رقمك 0565283375** أرسل رسالة إلى الرقم **+34634** واكتب فيها بالحرف:
   ```
   I allow callmebot to send me messages
   ```
2. CallMeBot يرد عليك برسالة فيها **رقم المفتاح** (مثل `1234567`).
3. ضعه في `server/config.json`:
```json
"whatsapp": {
  "enabled": true,
  "phone": "966565283375",
  "apiKey": "1234567"
}
```
4. اختبر فورًا:
```bash
npm run setup:whatsapp     # يرسل رسالة تجريبية لرقمك ويؤكد الوصول
```
5. أعد تشغيل الخادم (`start.bat` أو `npm start`) ←从此 كل طلب يصل جوّالك تلقائيًا.

> إذا لم يرد CallMeBot: أعد إرسال رسالة التفعيل، أو جرّب بعد دقائق (الرد قد يتأخر)،
> وتأكد أن واتسابك متصل بالإنترنت. الحد المجاني يسمح بعدد محدود من الرسائل.
> (إن استُخدم كثيرًا، فعّل قناة SMS بالأسفل.)

الطلبات **تُحفظ دائمًا** في قاعدة البيانات وتظهر في لوحة التحكم.
وإضافةً لذلك يمكنك تفعيل إشعار يصل جوّالك. فعّل **قناة واحدة على الأقل** من `server/config.json`:

### ✅ الخيار 1: واتساب (CallMeBot) — مُعدّ لرقمك +966565283375
خطوات التفعيل الكاملة في قسم «كيف أعرف أن العميل طلب؟» أعلاه.
الإعداد في `server/config.json`:
```json
"whatsapp": {
  "enabled": true,
  "phone": "966565283375",
  "apiKey": "1234567"
}
```

### ✅ الخيار 2: رسالة SMS حقيقية (Twilio)
```json
"sms": {
  "enabled": true,
  "accountSid": "ACxxxxxxxxxxxxxxxx",
  "authToken": "xxxxxxxxxxxx",
  "from": "+966500000000",
  "to": "+966500000000"
}
```
1. أنشئ حسابًا في [twilio.com](https://www.twilio.com/try-twilio) (رصيد تجريبي مجاني).
2. من Console › Phone Numbers احصل على رقم مُرسِل (`from`).
3. `accountSid` و `authToken` من Settings › API Keys.
4. الرسالة تُرسل بنسخة مختصرة مناسبة لطول SMS.

### ✅ الخيار 3: بوابة SMS/واتساب خاصة بك
```json
"gateway": {
  "enabled": true,
  "url": "https://api.company.com/send?phone={{phone}}&message={{message}}",
  "phone": "966500000000",
  "apiKey": "",
  "apiKeyHeader": ""
}
```
المتغيران `{{phone}}` و `{{message}}` يُستبدلان تلقائيًا. يناسب مزودي الرسائل
السعوديين (موبايلي،_Unifonic، SMSAA) أو أي بوابة لديك.

### ✅ الخيار 4: تيليجرام
1. افتح [@BotFather](https://t.me/BotFather) → `/newbot` → احصل على **Token**.
2. أرسل `/start` للبوت، ثم افتح [@userinfobot](https://t.me/userinfobot) لمعرفة **chatId**.
3. في `server/config.json`:
```json
"telegram": { "enabled": true, "botToken": "123456:ABC...", "chatId": "987654321" }
```

### ✅ الخيار 5: بريد إلكتروني — إلى `robamahmoud52@gmail.com` (مُعدّ)
**أ) من الخادم المحلي (Node) — عبر Gmail مباشرة (SMTP بدون مكتبات):**
```json
"smtp": {
  "enabled": true,
  "host": "smtp.gmail.com", "port": 465, "secure": true,
  "user": "robamahmoud52@gmail.com",
  "pass": "كلمة_App_Password_من_Google",
  "from": "robamahmoud52@gmail.com",
  "to": "robamahmoud52@gmail.com"
}
```
1. افتح <https://myaccount.google.com/apppasswords> وسجّل الدخول بـ `robamahmoud52@gmail.com`.
2. فعّل «التحقق بخطوتين» إن لم يكن مفعّلًا، ثم أنشئ **App Password** (16 حرفًا).
3. ضعها في `pass` ثم اختبر:
```bash
npm run setup:email     # يرسل بريدًا تجريبيًا ويؤكد الوصول
```
> Gmail لا يقبل كلمة مرور الحساب العادية — يلزم **App Password** دائمًا.
> الحد المجاني ≈ 500 رسالة/يوم (يكفي لآلاف الطلبات).

**ب) من Cloudflare Worker — عبر Resend (SMTP غير متاح داخل Workers):**
```toml
# worker/wrangler.toml
[vars]
RESEND_API_KEY = "re_xxxxxxxx"
EMAIL_FROM = "orders@quraishidates.com"
EMAIL_TO = "robamahmoud52@gmail.com"
```
أنشئ مفتاحًا مجانيًا في <https://resend.com> (3000 رسالة/شهر). بديل: Brevo (300 رسالة/يوم مجانًا).

**ج) اختبار بروتوكول البريد:**
```bash
npm run test:smtp      # 9 فحوصًا لعميل SMTP مقابل خادم بريد وهمي
```

### ✅ الخيار 6: Webhook (Zapier / Make / سكربتك)

## 🌐 النشر على الإنترنت

المشروع **خادم Node حقيقي**، لذلك لا يكفي رفع الملفات على GitHub Pages.

### Render.com (مجاني وسريع)
1. ارفع المشروع على GitHub.
2. في Render اختر **New › Web Service** وأربط المستودع.
3. الإعدادات:
   - Build Command: `node tools/generate-images.js`
   - Start Command: `npm start`
4. أضف المتغيرات (Secrets): `ADMIN_PASSWORD`, `WHATSAPP_ENABLED`, `WHATSAPP_PHONE`,
   `WHATSAPP_APIKEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, … (نفس أسماء `server/config.json`).
5. Render يعطيك رابطًا مثل `https://quraishi-dates.onrender.com` — منه الموقع ولوحة التحكم.
6. **مهم:** مجانيتي Render قرص مؤقت ⇒ أضف **Persistent Disk** على المسار `data/`
   أو استخدم متغير `DATABASE_FILE` لتثبيت مكان قاعدة البيانات.

### خادم VPS / استضافة تقليدية
```bash
npm install          # لا يوجد شيء للتثبيت فعليًا
node tools/generate-images.js
node server/server.js   # أو استخدم pm2:  pm2 start server/server.js --name quraishi
```
وفوقه Nginx كـ reverse proxy مع شهادة HTTPS.

### متطلبات بيئة الاستضافة
| المتطلب | ملاحظة |
|---|---|
| Node.js ≥ 22.5 | لأن `node:sqlite` مدمج |
| `PORT` من البيئة | تلقائيًا يحدّد المنفذ |
| `DATABASE_FILE` | مسار دائم لقاعدة البيانات |
| مجلد `data/` قابل للكتابة | أو مجلد قرص دائم |
| متغيرات البيئة | تُستخدم بدل `config.json` (أفضل للأسرار) |

> إن نشرت **الواجهة فقط** على نطاق منفصل (GitHub Pages) فالخادم يجب أن يكون على
> `https://...` — النظام يدعم CORS تلقائيًا، ويكفي وضع عنوان الخادم في
> `js/app.js` عبر `window.QC_API_BASE = 'https://api.example.com'` قبل سطر
> `js/app.js` في `index.html`.

## 🛠️ التخصيص

### إضافة صنف جديد
في `js/catalog.js` أضف سطرًا واحدًا:
```js
{ slug: 'nabaliq', ar: 'تمر نَبَالي', en: 'Nabaliq Dates',
  descAr: 'وصف الصنف بالعربية.', descEn: 'Description in English.',
  origin: 'Al-Qassim' },
```
ثم `npm run images` لتوليد الصورة. **الأسعار 5/10/15 ريال تُضاف تلقائيًا** للصنف الجديد
لأنه يأخذ نفس خيارات `SIZES` — لا حاجة لتعديل أي مكان آخر.

### تغيير الأسعار
`js/catalog.js` → مصفوفة `SIZES = [5, 10, 15]` (تُطبَّق على كل الأصناف).
لتغيير سعر صنف واحد فقط: عدّل `price` في دالة بناء `products` داخل نفس الملف.

### استبدال الصور بصور حقيقية
ضع صورك في `assets/photos/` بنفس أسماء الأصناف (مثل `ajwa.jpg`) وعدّل
`image:` في `js/catalog.js` إلى `assets/photos/ajwa.jpg`.

## 🔒 ملاحظات أمنية

- لا توجد أي مفاتيح أو كلمات مرور داخل واجهة المستخدم (HTML/CSS/JS).
- `server/config.json` هو المكان الوحيد للأسرار — ولا يُخدَم عبر المتصفح.
- عند النشر: استخدم متغيرات البيئة بدل الملف، وغيّر كلمة مرور اللوحة.
- لا توجد في السلة أي مبالغ إجمالية أو وسائل دفع — فقط الأصناف والخيارات والكميات واسم المحل.

## ❓ حل المشاكل

| المشكلة | الحل |
|---|---|
| «تعذّر الوصول إلى خادم الطلبات» | شغّل `start.bat` ثم افتح `http://localhost:3100` |
